# BOOKFORYOU — визуальный фронтенд

Клиентское демо книжного проекта. React, TypeScript, Vite, CSS Modules. Без бэкенда, базы данных, регистрации, корзины, заказов и оплаты.

## Запуск

Нужен Node.js, совместимый с Vite 8 (20.19+ или 22.12+).

```sh
npm ci
npm run dev -- --host 127.0.0.1
```

Адрес локального сайта печатается в терминале. Сборка: `npm run build`; результат в `dist`. Для размещения SPA нужен fallback всех маршрутов на `index.html`.

## Текущая версия

- Главная: винный первый экран с комплектом, светлые редакционные блоки, интерактивный просмотр четырёх предметов, подарок и текст куратора.
- Страницы первого выпуска и коллекции сохранены; мобильное меню и переходы работают.
- Название книги, автор и юридические сведения — честные заглушки до получения материалов клиента. Цена из ТЗ: 4 900 ₽. Продажи не включены.
- Рендеры — демонстрационные материалы, а не фотографии готового тиража. Портрет куратора не подменяется сгенерированным.
- Переключение предметов работает только в браузере и не отправляет данные на сервер. Шрифты загружаются из Google Fonts с системными fallback.

## Где менять

- `src/pages/HomePage.tsx` и `HomePage.module.css` — главная и её композиция.
- `src/components/KitExplorer.tsx` — просмотр комплекта.
- `src/styles/tokens.css` — палитра и шрифты.
- `src/data/editions.ts` — данные выпуска и пути изображений.
- `src/assets/renders` — изображения.
- `tz.txt` — исходные требования. `docs/superpowers` — история согласованных направлений; текущий запрос ограничен фронтендом.

## Проверки

```sh
npm test -- --run
npm run test:e2e -- --workers=2
```

Браузерные тесты настроены на установленный Microsoft Edge: маршруты, меню, клавиатура, адаптивность, reduced motion и переключение предметов.
